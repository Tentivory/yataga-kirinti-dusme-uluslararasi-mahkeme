# Yatağa Kırıntı Düşme Uluslararası Mahkemesi

> Resmi slogan: *Kırıntı düşer, adalet kalkar.*

Bu yazılım, gece 02:17'de yatağa düşen kruvasan kırıntısını **uluslararası hukuk** çerçevesinde yargılar. Lahey'deki gerçek mahkemeler kıskançlıktan çatlar. Hiçbir kırıntı beraat etmez. Beraat etmeye kalkarsa yorgan itiraz eder.

## Neden var?

Çünkü yatak bir egemen topraktır. Kırıntı izinsiz giriştir. Sen de suç ortağısın çünkü kruvasanı yatakta yedin. Mahkeme bunu biliyor. Mahkeme her şeyi biliyor. Mahkeme yorganın altındadır.

## Kuruluş

```bash
python3 mahkeme.py
```

Bağımlılık yok. Sadece Python 3 ve biraz vicdan. Vicdan isteğe bağlıdır, kırıntı değildir.

## Ne yapar?

1. Sanığı (kırıntıyı) kaydeder.
2. Tanık dinler (yastık, yorgan, sol çorap, gece lambası).
3. Ceza ölçer: sürgün (süpürge), müebbet (çarşaf kıvrımı), idam (elektrik süpürgesi).
4. Kararı yüksek sesle okur. Komşu duyarsa bu bir uluslararası krizdir.
